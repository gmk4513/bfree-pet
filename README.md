# 비프리 데스크톱 펫

학사모 비프리가 바탕화면 아래를 걸어 다닙니다. 가끔 멈춰서 알통을 자랑하거나
벽돌을 쌓고, 주기적으로 한마디씩 합니다.

[학사모 비프리의 아파트 건설현장](https://gangmini.com/game/)에 나오는
그 캐릭터입니다.

---

## 받기

[Releases](../../releases/latest)에서 운영체제에 맞는 파일을 받으세요.

| | 파일 |
|---|---|
| 윈도우 | `...x64-setup.exe` (권장) 또는 `...x64_en-US.msi` |
| 맥 (M1 이후) | `...aarch64.dmg` |
| 맥 (인텔) | `...x64.dmg` |

### 윈도우에서 "PC를 보호했습니다" 가 뜬다면

정상입니다. 바이러스라서가 아니라, **서명 인증서를 안 샀기 때문**입니다.
윈도우는 처음 보는 프로그램에 전부 이 경고를 띄웁니다.

`추가 정보` → `실행` 을 누르면 설치됩니다.

### 맥에서 "확인되지 않은 개발자" 가 뜬다면

같은 이유입니다. 앱을 **오른쪽 버튼으로 눌러 `열기`** 를 고르면 한 번만 묻고
다음부터는 그냥 열립니다. 그냥 더블클릭하면 안 열립니다.

---

## 쓰기

- **왼쪽 버튼** — 반응합니다
- **오른쪽 버튼** — 끕니다

작업표시줄에 뜨지 않고 항상 맨 앞에 있습니다. 캐릭터 위가 아닌 곳은
전부 클릭이 통과하므로, 뒤에 있는 창을 쓰는 데 지장이 없습니다.

## 바꾸기

`pet.config.json` 의 값을 고치면 됩니다. 설치된 위치의 같은 폴더에 있습니다.

| 값 | 뜻 |
|---|---|
| `size` | 캐릭터 키(px) |
| `speed` | 걷는 속도(px/초) |
| `walkSec` / `restSec` | 걷는 시간 / 멈춰 있는 시간(초) |
| `bubbleGap` / `bubbleHold` | 말하는 간격 / 띄워 두는 시간(초) |
| `floorOffset` | 화면 아래에서 얼마나 띄울지. 작업표시줄 높이에 맞춥니다 |
| `poses` | 멈췄을 때 하는 자세 — `flex` `hammer` `work` `crawl` |
| `lines` | 말풍선 대사 |

## 만들기

```bash
npm install
npm run dev      # 개발 중 띄워 보기
npm run build    # 설치 파일 만들기
```

Rust 와 Node 가 필요합니다. 윈도우에서는 Visual Studio Build Tools 도 필요합니다.

### 내보내기

```bash
git tag v0.1.0
git push origin v0.1.0
```

GitHub Actions 가 윈도우·맥(애플 실리콘·인텔) 셋을 만들어 Releases 에
**초안**으로 올립니다. 내용을 확인하고 직접 `Publish` 를 눌러야 공개됩니다.

## 구조

```
ui/                    화면. 브라우저에서 index.html 을 열어도 그대로 돕니다
├── index.html
├── pet.css
├── pet.js             걷기·자세·말풍선 상태기계
├── pet.config.json    ★ 값은 여기만 고칩니다
└── sprites/           캐릭터 그림
src-tauri/             앱 껍데기 (투명 창, 항상 위, 클릭 통과)
└── src/main.rs
```

`ui/` 는 Tauri 없이도 돌아갑니다. 브라우저에서 열면 창 관련 기능만
건너뛰고 움직임은 똑같습니다. 그래서 움직임을 고칠 때 앱을 다시 빌드할
필요가 없습니다.
